Vetores:
O que são vetores:



Ê uma estrutura de dados que armazena uma coleção de elementos do mesmo tipo, em uma sequência linear.

Os elementos são acessados por meio de seus índices.



Matriz:



A matriz é uma coleção de vetores;



Array:
