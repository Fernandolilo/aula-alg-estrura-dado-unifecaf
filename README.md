Vetores:
O que são vetores:



Ê uma estrutura de dados que armazena uma coleção de elementos do mesmo tipo, em uma sequência linear.

Os elementos são acessados por meio de seus índices.



Vantagens: 



&#x09;Acesso rápido aos elementos, por meio de seus índices.

&#x09;Eficiente para operações como busca e atualizações

&#x09;facilidade de implantação e uso



Desvantagem:



&#x09;Tamanho fixo, limitando a capacidade de armazenamento.

&#x09;inserções ou remoções podem se lentas, se o vetor estiver cheio ou vazio.

&#x09;gasto de memoria para elementos não utilizados.

Linked List ou lista ligada.



É uma estrutura linear que armazena uma coleção de elementos, chamados 'nós' interconectados por um ponteiro,

cada NÓ contem um ponteiro para o próximo NÓ da lista.



Inserir:

Podemos Add em um novo nó em uma posição especifica da lista.



Remover:

Podemos remover um nó especifico da lista.



Atualizar:

Podemos modificar um valor de um nó especifico.



Buscar:

podemos efetuar uma busca em dados de um nó especifico.



Vantagens:

&#x09;Tamanho dinâmico, permitindo add, remover, de nós específicos, sem necessidade de redimensionamento de nós. 

&#x09;sendo eficiente para tanto add como remover posições da lista 



&#x09;Uso eficiente da memoria, apenas os nós utilizados são alocados na memória.



Desvantagens:



&#x09;Acesso lento a elementos específicos, requerendo uma interação pela lista.

&#x09;Implementação mais complexa, em comparação com vetor.

&#x09;Gasto de memoria para ponteiro.



\------------------------------------------------------------------------------------------------------



As Filas são:



As filas são uma estrutura de dados linear, que seguem o principio de FIFO (first-in, first-out) ou seja, o primeiro que entra é o primeiro a sair.
